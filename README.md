# Mi App — React + Vite

Aplicación web desarrollada con React y Vite como proyecto de aprendizaje.

## Tecnologías
- React 18
- Vite 5
- CSS Variables
- Git

## Componentes
- Header — navbar con links de navegación
- Footer — pie de página con año dinámico
- Card — componente reutilizable con props
- Contador — contador interactivo con useState
- ContactForm — formulario con validación y preview en vivo
- ProductList — lista filtrable por categoría y stock
- TodoApp — CRUD de tareas con filtros

## Instalación

```bash
npm install
npm run dev
```

Abrí el navegador en `http://localhost:3000`

## Scripts
- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
